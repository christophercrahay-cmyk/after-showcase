# Public disclosure policy

This repository is a technical showcase for the private AFTER project.

Game source code, Godot scenes and scripts, licensed or proprietary assets, internal tests, simulation rules, balancing data, development tooling and internal design/audit documents are intentionally excluded.

Architecture diagrams and gameplay descriptions are simplified public representations and are not the complete implementation.

If sensitive or licensed material is accidentally published, please avoid redistributing it and contact the repository owner through GitHub.
